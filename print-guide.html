Print Settings Guide

Getting perfect label alignment on Windows & Chromebook

Keep your Avery labels perfectly aligned

Labels only line up if the browser prints the page exactly as designed — that means 100% scale, no margins, no headers/footers, and background graphics switched on.

← Back to the label maker

The 5 golden rules (applies on every device)

  1. Destination: choose your printer (or Save as PDF).
  2. Paper size: A4 — not “Letter”, not “A5”.
  3. Scale: 100% — also called Actual size or Default. Never use “Fit to page”.
  4. Margins: None — the tool prints its own margins.
  5. Background graphics: ON, and Headers & footers: OFF.
⚠️ Don’t waste an Avery sheet: label sheets are expensive and every wasted sheet costs money. Always do at least one test print on plain paper first — with the dashed guides switched on — and hold it behind a blank label sheet against a window to confirm the boxes line up with the stickers. Only then print on the real sheets, with the guides off.
🧪 Test-print routine: ① print once with dashed guides ON on plain paper, ② hold it behind a blank label sheet against a window, ③ confirm the dashed boxes sit on the stickers, ④ switch guides OFF and print for real.
📏 Still slightly out? Some printers and browsers quietly add their own top/side margins. On the tool page, open Printing options → 🤏 Labels not lining up? and press 🖨️ Print test sheet. Measure the gap around the dashed boxes with a ruler, type it in (negative = moves up/left), press Apply & preview, then redo the test print. The offset is stored on that device, so you only fix it once per printer.

🪟 Windows

Google Chrome or Microsoft Edge — the settings are nearly identical in both.

1

Open the print dialog

Click the 🖨️ Print / Save as PDF button in the label maker (or press Ctrl + P).

2

Destination

Pick your label-ready printer, or choose “Save as PDF” to make a PDF file you can print later.

3

Pages & paper size

Set Pages: All. Under More settings → Paper size, select A4.

4

Critical — check the “More settings” box

SettingSet to
Paper sizeA4
MarginsNone
Scale100% / Default
Headers and footersOff (unchecked)
Background graphicsOn (checked)
5

Print

Hit Print. Run one test page first with the dashed guides on, then reuse the sheet of labels.

💡 Tip: the “Scale” setting is hidden until you tick More settings. It’s the #1 cause of misaligned labels.

💻 Chromebook

Uses Chrome — same dialog, a slightly different layout. Works with any network printer the school manages.

1

Open the print dialog

Click the 🖨️ Print / Save as PDF button (or press Ctrl + P).

2

Destination

Choose the printer under Destination, or pick “Save as PDF”. Many Chromebooks also show school printers here automatically.

3

Pages

Set Pages: All, and select Color (or black & white — your choice — but keep the accent bars coloured for best results).

4

Critical — open “More settings”

SettingSet to
Paper sizeA4
MarginsNone
Scale100% (not “Fit to printable area”)
Headers and footersOff (unchecked)
Background graphicsOn (checked)
5

Print

Tap Print. Chromebooks default some printers to Letter — double-check it says A4 before printing.

⚠️ Chromebooks sometimes select “Fit to printable area” automatically — if you see that, change it to a fixed 100% / Default. This is the most common reason labels come out misaligned from a Chromebook.

Labels not lining up? Check these

ProblemFix
Everything is slightly too small / has a white border around it Scale is not 100% — change “Fit to page” back to 100% / Default.
Labels shifted sideways or down Paper size is wrong (Letter instead of A4) or margins are not None.
Text/boxes all grey or invisible Background graphics is off — switch it on.
Extra line prints at the top showing the URL/date Headers and footers is on — switch it off.
Colour comes out pale Ensure printer is set to Color (not Greyscale) for the accent bars.
